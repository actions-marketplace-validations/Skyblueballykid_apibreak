Legacy: `GET /v1/old-thing`.

Charge a card (form encoded):

```bash
curl https://api.acme.test/v1/charges \
  -u sk_test_123: \
  -d amount=2000 \
  -d currency=usd \
  -d "metadata[order_id]"=6735
```

Events accept any properties:

```bash
curl -X POST https://api.acme.test/v1/events/ -d '{"type": "ping", "anything": true}'
```

Pay by IBAN:

```python
requests.post("https://api.acme.test/v1/payments", json={"amount": 100, "iban": "DE00"})
```

Search with a filter:

```bash
curl -G https://api.acme.test/v1/search --data-urlencode "q=ada" --data-urlencode "filter[status]=active"
```

curl -X POST https://api.acme.test/v1/customers -d @customer.json -H 'Content-Type: application/json'
